### Menu Array Description

The menu array contains the following elements:

- Index 0: Start Signal (0 for normal, 1 for activate)
- Index 1: Toggle the ingredient motors Signal (0 for normal, 1 for activate)
- Index 2: ingrTim for ingr1
- Index 3: ingrTim for ingr2
- Index 4: ingrTim for ingr3
- Index 5: ingrTim for ingr4
- Index 6: ingrTim for ingr5
- Index 7: Steps for Top Motor 
- Index 8: Steps for Linear Motor
- Index 9: Steps for Tilt Motor
- Index 10: Toggle for Making Motors go one by one (0 for normal, 1 for active)
